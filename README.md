# AdminPRO

AdminPRO is a Windows administration utility designed to provide quick access to system tools and maintenance functions.

## Features

AdminPRO provides access to various Windows administration and maintenance features, including:

- System and hardware information
- Task Manager
- Disk Cleanup
- System and user temporary file cleanup
- Disk management
- Device Manager
- Registry Editor
- Task Scheduler
- Local Users and Groups
- Group Policy
- Windows Settings
- File Explorer access
- UEFI restart
- Windows Defender real-time protection control
- Restore point management

Some features require administrator privileges.

## Important

AdminPRO includes functions that can make significant changes to the system.

Some operations can:

- Temporarily disable Microsoft Defender real-time protection
- Delete restore points from the C: drive
- Remove temporary files and system data
- Restart the computer directly into UEFI firmware settings

Use these functions carefully and only when you understand what they do. AdminPRO does not make these changes automatically without the user selecting the corresponding function.
